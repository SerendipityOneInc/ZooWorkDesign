# 首版视觉素材处理结果

授权与精确哈希见 [DESIGN_ASSETS.md](../../DESIGN_ASSETS.md) 和 [ASSET_MANIFEST.json](../../ASSET_MANIFEST.json)。预览另含 2 张原创头像及 1 个本地生成的通用示例视频。
