# Figma resources

ZooWorkDesign's Figma candidate includes foundations, light/dark variables, component variants, reusable patterns and Chat Alpha examples. The Community publication and external-copy verification are still pending; the official link will be added here after both succeed.

Design files describe appearance and reusable properties. React defines runtime keyboard/focus behavior, browser controls, data integration and message sending. Native iOS/macOS implementation is not included.
