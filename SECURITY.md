# Security reporting / 安全问题反馈

Please do not disclose exploit details, credentials or customer data in a public issue or pull request.

If available for this repository, use GitHub's **Security → Report a vulnerability** to submit a private report: [private reporting](https://github.com/SerendipityOneInc/ZooWorkDesign/security/advisories/new). This file does not enable that GitHub feature. If the entry is unavailable, open an issue titled **Private security contact request** with no vulnerability details, and wait for the maintainer to provide a private channel.

Include the affected package/version, environment, impact and a minimal reproduction through the private channel. Prefer synthetic data and a minimal demonstration over a deployed exploit. This project is maintained by one person and does not promise a fixed response deadline or a bounty.

Updates target the current design-system release and current Chat UI alpha. Older versions do not have a promised backport window. Consumers manage their own application authentication, APIs and dependency upgrades.

中文：安全问题优先通过仓库已启用的 GitHub 私密报告入口提交；若入口不可用，仅公开请求私下联系方式，不披露漏洞细节。报告应注明版本、影响范围和最小复现。项目由单人维护，目前不承诺固定响应时限、历史版本回补或奖金。
