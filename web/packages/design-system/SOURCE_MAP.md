# Component source map

This package is maintained in [ZooWorkDesign](https://github.com/SerendipityOneInc/ZooWorkDesign/tree/main/web/packages/design-system).

- `src/components`: reusable foundations and UI primitives.
- `src/product-patterns`: workspace navigation, forms, account and other reusable patterns.
- `src/layouts` and package CSS: shared layout and theme implementation.
- `assets`: bundled fonts, original illustrations and explicitly scoped brand resources.

Adapted shadcn/ui and Heroicons files, upstream source references, copyright notices and modifications are recorded in [third-party/SOURCE_ATTRIBUTION.md](third-party/SOURCE_ATTRIBUTION.md). Original third-party license texts are preserved verbatim. Artwork and fonts are mapped by file and hash in ASSET_MANIFEST.json and the repository third-party inventory.

Product APIs, authentication, routing and persistence are not included. This public source snapshot does not include internal application repositories or their Git history.
